Privacy Policy

ETS2 Mod Hunter

Last updated: November 24, 2026

ETS2 Mod Hunter is a Telegram bot designed to help users discover, browse, save, and share Euro Truck Simulator 2 mods from Steam Workshop.

1) Information we collect

  • Telegram user ID
  • Telegram username and display name
  • Preferred language
  • Saved favorites
  • Search history within the bot
  • Basic interaction data needed to run the bot

2) How we use the information

  • Show personalized greetings
  • Remember your language choice
  • Save your favorites
  • Improve search and browsing
  • Deliver automatic mod updates to the Telegram channel

3) Data sources

Mod content is sourced only from Steam Workshop. User data comes only from Telegram interactions with the bot.

4) Data sharing

We do not sell user data. We only use data needed to operate the bot and publish mod updates.

5) Storage and security

  • User preferences and favorites may be stored in a database
  • Data is protected with reasonable security measures
  • We keep only the data required for bot functionality

6) User control

  • Change your language anytime
  • Remove mods from favorites
  • Stop using the bot at any time

7) Third-party services

This bot may use Telegram and Steam Workshop.

8) Changes to this policy

We may update this Privacy Policy when needed. Continued use of the bot means you accept the updated policy.

9) Contact

If you have questions about this policy, contact the bot administrator through the bot’s support or official contact channel.
